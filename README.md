# Mt.Pyxel

Pyxelで制作したゲームを投稿できるプラットフォームです。
投稿用のアカウントを作成し、Pyxelを実行できるWebリンクとサムネイル、プロジェクトの説明などを書いて投稿します。

## 特徴
- プロジェクトをタグやキーワードで検索することが可能

## 使用技術
- Flutter
- Firebase

## 実行方法
リポジトリをクローンし、以下のコマンドで実行できます。

\`\`\`bash
# リポジトリのクローン
git clone https://github.com/kai-tokei/mt_pyxel.git
cd mt_pyxel

# 依存パッケージのインストール
flutter pub get

# 実行
flutter run
\`\`\`
